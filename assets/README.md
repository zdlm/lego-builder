# Assets

- `music/` — background tracks. Must allow commercial use on social media.
- `sfx/` — click / snap sound effects (`.wav` or `.mp3`). The pipeline rotates through all files here (one file is fine: it is played on every snap at slightly varied volume). Leading silence is measured and compensated, so the click lands on the beat.
- `fonts/` — brand fonts.

Large or licensed files are fine to keep locally; record every file below before using it in a published video.
